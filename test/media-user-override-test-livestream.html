Live Stream Test

Live streams have duration = Infinity. The control bar should show a "LIVE" badge instead of a progress bar. Time display should show "LIVE" instead of timestamps.

1. Canvas Live Stream (Simulated)

Generates a live video stream from canvas animation. Duration will be Infinity.

2. Webcam Live Stream

Uses your webcam as a live stream source. Duration will be Infinity.

3. Audio Live Stream (Oscillator)

Generates a live audio stream from Web Audio API. Duration will be Infinity.

4. Combined A/V Live Stream

Combines canvas video + audio oscillator into a single live stream.
